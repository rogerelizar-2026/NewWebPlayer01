USB DRIVE / GITHUB PAGES · instruções de uso e salvamento

Para usar por USB, copie este index.html para uma pasta ou unidade e abra no navegador; selecione áudio local em “Abrir arquivo”. Para publicar, envie o arquivo ao repositório GitHub e ative GitHub Pages em Settings → Pages. O player e os arquivos locais não exigem build, Node.js ou chave paga. Busca, letras, tradução, capas e metadados precisam de internet e dependem da disponibilidade/CORS de cada fonte pública; alguns navegadores limitam APIs externas em file://, então GitHub Pages oferece a maior compatibilidade. O áudio pesquisado toca diretamente pelo HTML5, sem criar uma rota de áudio Web Audio.
